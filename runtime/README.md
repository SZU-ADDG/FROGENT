# FROGENT runtime

This directory contains local execution state for FROGENT:

- `app/`: the application environment, uploads, memory database, and generated static files;
- `tools/`: project-local scientific executables, environments, source packages, and canary outputs;
- `evaluation/`: datasets and retained outputs from bounded Agent evaluations;
- `cache/`: package-manager and model caches;

Only this README is tracked. Runtime payloads remain local and must not contain credentials.
