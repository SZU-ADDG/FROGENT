# FROGENT manuscript brief

## Publication thesis

- One-sentence thesis: Evidence-controlled orchestration allows pretrained language models to connect heterogeneous drug-discovery resources into an auditable computational decision process without task-specific parameter training.
- Reader memory sentence: FROGENT improves a base model by controlling evidence, tools and scientific state rather than by retraining the model.
- Important scientific problem: Drug-discovery models and databases remain operationally fragmented, making multi-stage scientific decisions difficult to execute, inspect and revise.
- Distinctive capability or discovery: One runtime coordinates retrieval, small-molecule and peptide design, structural evaluation and retrosynthesis while preserving provenance, uncertainty and recoverable state.
- Winning dimension or condition: Same-model direct versus FROGENT comparisons across eight exposed task categories, complemented by aligned current-system adaptations and executable design studies.
- Exact demonstrated scope: Computational exposed benchmarks, structured retrieval, generation, docking/geometry, peptide prioritization and retrosynthesis; no wet-lab efficacy claim.
- Field-level consequence: Agentic drug discovery should be evaluated by evidence binding, tool execution, recovery and decision trace rather than by unconstrained language-model answers alone.

## Publication strategy

- Why this problem deserves attention now: Capable foundation models and specialized scientific tools exist, while reliable integration and evidence control remain limiting.
- Closest alternatives: CLADD, Prompt-to-Pill and Robin establish complementary retrieval, molecular-design and target-discovery workflows.
- Consequential capability that remains open: A common computational framework spanning molecular and peptide workflows with typed evidence and tool-state control.
- Why the present advance resolves that gap: FROGENT uses role specialization, evidence admission, shared state and typed scientific tools without task-specific parameter updates.
- Where the advantage should be clearest: Tasks requiring structured identifiers, cross-tool synthesis, iterative allocation or recovery from incomplete evidence.
- Strongest evidence: All fixed base models improved in the paired exposed panel; typed retrieval exceeded the aligned Robin adaptation; the Forge--Gauge study showed that one feedback allocation improved over uniform single-pass generation.
- Story reconstruction trigger: Rebuild the argument if the final public package cannot reproduce the frozen scorers or if repository audit invalidates the stated evaluation isolation.

## Scientific argument

- Biological or scientific significance: The framework makes multi-stage computational drug-design evidence easier to combine and inspect before experimental prioritization.
- Decisive obstacle: Heterogeneous interfaces, incompatible identifiers, uncertain provider outputs and weak separation between evidence and interpretation.
- Organizing concept: Evidence-controlled orchestration.
- Distinctive mechanism: Typed provider binding, evidence gates, shared state, role-specific tool portfolios and explicit recovery.
- Decisive validation: Same-model before/after comparison, aligned external-system cells, structured retrieval and matched-budget feedback allocation.
- Alternative explanation to exclude: Gains arise solely from selecting a stronger base model. The paired design holds the base model fixed.
- Meaningful tradeoff: Tool evidence can mislead when similarity is mistaken for affinity or when a structured source is incomplete; negative ChEMBL and co-crystal-ligand follow-ups establish this boundary.
- Final field judgment: FROGENT is a computational research framework for evidence-grounded prioritization, not an autonomous substitute for experimental validation.
